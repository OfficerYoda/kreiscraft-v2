# Kreiscraft

Combined Paper 1.21.11 plugin — gameplay + admin + web API bridge.

## Development

- `./gradlew build` — compile + Spotless check.
- `./gradlew test` — run tests.
- `./gradlew runServer` — start a local Paper test server with the plugin.
- `./gradlew spotlessApply` — auto-format sources.

See `docs/development.md` for architecture and module authoring guide.
